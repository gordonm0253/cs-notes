# CS Notes

Compilation of notes and visualizations from some of Cornell's CS classes. Primarily for CS4820: Introduction to Analysis of Algorithms (work in progress), but in future may add notes from other courses (discrete structures, theory of computing). Website format built using [Docusaurus](https://docusaurus.io/), a modern static website generator.

## Installation

```bash
npm install
```

## Local Development

```bash
npm run start
```

This command starts a local development server and opens up a browser window. Most changes are reflected live without having to restart the server.
