NP-Completeness

Introduction​

So far, we have designed efficient algorithms for a wide range of problems. But not all problems are so accomodating. In this section, we examine a class of problems for which no polynomial time algorithm is known (and for which there is strong theoretical reason to believe none exists).

Definitions​

We study NP-completeness in the setting of decision problems, or problems with a yes/no answer. This is not much of a restriction, since most optimization problems that we have previously studied have a natural decision version (e.g. "for a graph G=(V,E)G=(V,E)G=(V,E), does there exist a traveling salesman tour of cost at most kkk?").

We say a (decision) problem AAA is in NP if a proposed solution can be verified in polynomial time. More precisely, there exists a polynomial-time algorithm that, given an instance xxx of AAA and a certificate ccc, correctly determines whether ccc proves that xxx is a yes-instance of problem AAA. For example, a certificate (proposed solution) for a SAT instance is a truth assignment to its variables; we can check in polynomial time whether this assignment satisfies the SAT formula.

A polynomial reduction reduction from problem AAA to problem BBB, written as A≤PBA \le_P BA≤P​B, is a polynomial-time computable function fff such that for any instance xxx of AAA, xxx is a yes-instance of AAA if and only if f(x)f(x)f(x) is a yes-instance of BBB. Intuitively, this means AAA is "no harder" than BBB; given an efficient algorithm for BBB, we obtain an efficient algorithm for AAA by transforming instances via fff and running BBB's algorithm on the result. Note the direction; A≤PBA \le_P BA≤P​B means BBB is at least as hard as AAA, a fact we will use when proving NP-hardness.

We say a problem BBB is NP-hard if A≤PBA \le_P BA≤P​B for every problem A∈NPA \in \mathrm{NP}A∈NP. Intuitively, BBB is at least as hard as every problem in NP; solving BBB efficiently would let us solve all of NPNPNP efficiently.

We say AAA is NP-Complete if and only if the following conditions are true:

  • A∈NPA \in \mathrm{NP}A∈NP: there exists a verifier that can check proposed solutions to an instance xxx of AAA in polynomial time.
  • AAA is NP-hard. To show this, we produce a polynomial-time reduction B≤PAB \le_P AB≤P​A from some problem BBB already known to be NP-hard. By transitivity of ≤P\le_P≤P​, since every problem in NP reduces to B (as B is NP-hard) and B≤PAB \le_P AB≤P​A, every problem in NP also reduces to AAA; so AAA is NP-hard.

General Framework​

NP-completeness proofs are an important part of CS4820, and they are sure to show up on exams. If you want to show that some decision problem AAA is NP-complete, the proof generally has 4 steps, as follows:

  1. A∈NPA \in \mathrm{NP}A∈NP. Show that there is a polynomial-time verifier for AAA. It should take in an instance of the problem Foo and a certificate (possible solution) to that instance, answering 'yes' if certificate is a correct solution and 'no' otherwise. This is usually straightforward and should almost always be done first. Don't forget to argue why the verifier runs in polynomial time!
  2. Reduce from some NP-complete problem XXX to AAA (i.e. showing X≤PAX \le_P AX≤P​A). You should pick a known NP-complete problem XXX. Your goal is to solve XXX using an algorithm that solves AAA. You should do this by "reducing" or translating an arbitrary instance of XXX into an equivalent instance of AAA. This way, if you have an algorithm that solves AAA, you can solve XXX by reducing the problem to AAA and running the algorithm for AAA.
  3. Show that the reduction takes polynomial time. Make sure you aren't creating exponentially many gadgets/nodes!
  4. Show that your reduction is equivalent. In other words, xxx is a yes-instance of XXX iff f(x)f(x)f(x) is a yes-instance of AAA (where fff is our reduction function). This has two parts.
  • (⇒)(\Rightarrow)(⇒) If xxx is a yes-instance of XXX, then f(x)f(x)f(x) is a yes-instance of AAA. Typically, you show this by taking an arbitrary solution to xxx and explicitly constructing a corresponding solution to f(x)f(x)f(x).
  • (⇐)(\Leftarrow)(⇐) If f(x)f(x)f(x) is a yes-instance of AAA, then xxx is a yes-instance of XXX. You show this by taking a solution to f(x)f(x)f(x) and explicitly constructing a corresponding solution to xxx. This is often the harder direction, since you need to consider all possible solutions to f(x)f(x)f(x) (not just the ones you had in mind while making the reduction construction).

Example Problem: Independent Set​

Independent Set: Given an undirected graph G=(V,E)G = (V, E)G=(V,E) and integer kkk, we say that a set of nodes S⊆VS \subseteq VS⊆V is independent if no two nodes in SSS are joined by an edge. Does there exist an independent set of size at least kkk?

Show that Independent Set is NP-Complete.

We first show that Independent Set is in NP. Given a graph instance G=(V,E)G = (V, E)G=(V,E) and certificate (proposed solution) SSS, we check that the following conditions are true. If any of them do not hold, then we output "no". Otherwise, we output "yes".

  • Check that SSS is at least size kkk (verify ∣S∣≥k|S| \ge k∣S∣≥k).
  • For each pair of nodes u,v∈Su, v \in Su,v∈S with u≠vu \ne vu=v, ensure (u,v)∉E(u, v) \notin E(u,v)∈/E. In other words, no node pair in SSS should form an edge in GGG.

We observe that this verifier runs in polynomial time. Since S⊆VS \subseteq VS⊆V, checking the first condition takes O(∣V∣)O(|V|)O(∣V∣) time. For the second condition, we consider all pairs of nodes in SSS and check membership in EEE; there can be at most O(∣V∣2)O(|V|^2)O(∣V∣2) pairs and a naive membership check in EEE takes O(∣E∣)O(|E|)O(∣E∣) time. Thus, our verifier runs in O(∣V∣2⋅∣E∣)O(|V|^2 \cdot |E|)O(∣V∣2⋅∣E∣) time, which is indeed polynomial.

We show that Independent Set is NP-Hard by showing a reduction from 3SAT.

Recall that 3SAT gives a 3CNF (AND of ORs) of clauses with exactly three variables, where the 3CNF is satisfiable if there exists a boolean assignment of variables that satisfy all clauses. For example, the following 3CNF is satisfiable by setting x1x_1x1​ and x3x_3x3​ to be true and x2x_{2}x2​ to be false (there are other satisfying sets of variable assignments).

(x1∨¬x3∨x2)∧(¬x1∨¬x3∨¬x2)∧(¬x1∨x3∨x2) \begin{align*} (x_1 \lor \lnot x_3 \lor x_2) \land (\lnot x_1 \lor \lnot x_3 \lor \lnot x_2) \land (\lnot x_1 \lor x_3 \lor x_2) \end{align*}(x1​∨¬x3​∨x2​)∧(¬x1​∨¬x3​∨¬x2​)∧(¬x1​∨x3​∨x2​)​

Given a 3CNF ϕ\phiϕ of mmm clauses and nnn variables, we create a graph GGG that we can run an algorithm for Independent Set on. For clause iii, we create 3 nodes xij1x_{ij_1}xij1​​, xij2x_{i j_2}xij2​​, and xij3x_{i j_3}xij3​​, representing the three literals in clause iii. We connect these three nodes with edges forming a triangle. Additionally, for every pair of nodes representing a variable and its negation (i.e. xijx_{ij}xij​ and ¬xij\lnot x_{ij}¬xij​) across all clauses, we add an edge between them. We set k=mk = mk=m.

We argue that this reduction takes polynomial time. For each of the mmm clauses, we create 3 nodes and 3 edges (to connect them all together) in our graph. In addition, we connect all pair of nodes representing variables and their negation. There are at most (3m)2=O(m2)(3m)^2 = O(m^2)(3m)2=O(m2) pairs possible, so we can reduce our 3SAT instance to an Independent Set instance in O(m2+m)=O(m2)O(m^2 + m) = O(m^2)O(m2+m)=O(m2) time, which is polynomial.

The intuition is that each clause is represented by a gadget of "nodes" in our graph GGG. Since k=mk = mk=m in our Independent Set instance, we must pick exactly one node from each clause gadget to be in the independent set SSS (the triangle edges prevent picking two nodes from the same gadget). Picking a node xijx_{ij}xij​ corresponds to setting that literal to true. The consistency edges between contradictory literal pairs ensure we never pick both a variable and its negation (which would violate the independent set property), so the assignment is well-defined and satisfies every clause.

(⇒)(\Rightarrow)(⇒) Suppose the 3CNF ϕ\phiϕ is satisfiable. We show that a satisfying assignment of variables to a 3SAT instance implies an independent set solution to our constructed graph. Fix a satisfying assignment. For each clause iii, at least one of its three literals is true under this assignment; pick one such true literal and include its corresponding node xijx_{ij}xij​ in SSS. This gives ∣S∣=m≥k|S| = m \ge k∣S∣=m≥k.

We check that SSS is independent. No two nodes lie in the same clause gadget, since we picked exactly one per gadget (no triangle edges are present within SSS). Also, no two chosen nodes correspond to a variable and its negation: since both nodes would have to present true literals under the same assignment, a variable and its negation cannot both be true. Hence, no consistency edge connects two nodes of SSS. So SSS is an independent set of size m=km = km=k.

(⇐)(\Leftarrow)(⇐) Suppose GGG has an independent set SSS with ∣S∣=k=m|S| = k = m∣S∣=k=m (we know it cannot go any higher because exactly one node can be picked per clause gadget, and there are mmm of them).

Define a variable assignment by setting each literal corresponding to a node in SSS to true (if a variable has neither literal represented in SSS, then assign it arbitrarily). This assignment is well defined; if both xijx_{ij}xij​ and ¬xi′j\lnot x_{i'j}¬xi′j​ were in SSS, it would not be an independent set because they are connected by an edge. So no variable is assigned conflicting values. Since SSS contains one node per clause gadget, every cluase has at least one literal set to true, so every clause is satisfied. Hence ϕ\phiϕ is satisfiable.

Therefore, our 3CNF ϕ\phiϕ is satisfiable if and only if GGG has an independent set of size k=mk = mk=m, completing the reduction. Combined with the polynomial-time verifier shown earlier, Independent set is NP-complete.

Known NP-Complete Problems​

The known NP-complete problems fall into several natural categories. On assignments or exams, you may freely cite NP-complete problems that have appeared in class, previous assignments, or in the textbook.

Packing Problems​

If your problem has a parameter kkk for which as kkk gets larger the problem gets harder, try reducing from:

  • Independent Set: Given an undirected graph G=(V,E)G = (V, E)G=(V,E) and integer kkk, we say that a set of nodes S⊆VS \subseteq VS⊆V is independent if no two nodes in SSS are joined by an edge. Does there exist an independent set of size at least kkk?
  • Set Packing: Given a universe UUU, subsets S1,…,Sm⊆US_1, \dots, S_m \subseteq US1​,…,Sm​⊆U, and an integer kkk, does there exists a subcollection of {S1,…,Sm}\{S_1, \dots, S_m\}{S1​,…,Sm​} of at least kkk pairwise-disjoint subsets?

Covering Problems​

If your problem has a parameter kkk for which as kkk gets larger the problem gets easier, try reducing from:

  • Vertex Cover: Given an undirected graph G=(V,E)G = (V, E)G=(V,E) and an integer kkk, we say that a set of nodes S⊆ES \subseteq ES⊆E if every edge e∈Ee \in Ee∈E has at least one endpoint in SSS. Does there exist a vertex cover of size at most kkk?
  • Set Cover: Given a universe UUU, subsets S1,…,Sm⊆US_1, \dots, S_m \subseteq US1​,…,Sm​⊆U, and an integer kkk, does there exist a subcollection of {S1,…,Sm}\{S_1, \dots, S_m\}{S1​,…,Sm​} of at most kkk sets whose union is all of UUU?

Partitioning Problems​

If your problem involves dividing elements into disjoint groups, try reducing from:

  • 3D Matching: Given disjoint sets X,Y,ZX, Y, ZX,Y,Z each of size nnn, a set of triples T⊆X×Y×ZT \subseteq X \times Y \times ZT⊆X×Y×Z, does there exist a set of nnn triples in TTT such that every element of X∪Y∪ZX \cup Y \cup ZX∪Y∪Z is contained in exactly one of these triples?
  • 3-Coloring: Given an undirected graph G=(V,E)G = (V, E)G=(V,E), does GGG have a 3-coloring?

Sequencing Problems​

If your problem involves giving an ordering over nnn items, try reducing from:

  • Hamiltonian Cycle: Given a graph GGG (either directed or undirected), is there a Hamiltonian cycle (a path starts and ends with the same node and visits every other node exactly once)?
  • Hamiltonian Path: Given a graph GGG (either directed or undirected), start node sss and end node ttt, is there a Hamiltonian path starting at sss and ending at ttt?

Other​

If your problem involves summing over numeral values to reach a target, try reducing from:

  • Subset Sum: Given nonnegative integers w1,…,wnw_1, \dots, w_nw1​,…,wn​ and a target integer WWW, does there exist I⊆{1,…,n}I \subseteq \{1, \dots, n\}I⊆{1,…,n} such that ∑i∈Iwi=W\sum_{i \in I} w_i = W∑i∈I​wi​=W?

If all else fails, try 3-SAT!

  • 3SAT: Given a CNF with clauses of 3 literals each, does there exist a satisfying assignment?

Problem 4. [Partition] The input to the Partition problem is a set of nnn large integers w1,…,wnw_1, \dots, w_nw1​,…,wn​. The problem is to decide if there is a subset I⊂{1,…,n}I \subset \{1, \dots, n\}I⊂{1,…,n} such that ∑i∈Iwi=∑i∉Iwi\sum_{i \in I} w_i = \sum_{i \notin I} w_i∑i∈I​wi​=∑i∈/I​wi​.

Show that Partition is NP-Complete.

Hint

Reduce from Subset Sum.

Solution

We first show that Partition is in NP. Given a Partition instance of nnn large numbers w1,…,wnw_1, \dots, w_nw1​,…,wn​, our certificate is a set III. We can simply check if ∑i∈Iwi=∑i∉Iwi\sum_{i \in I} w_i = \sum_{i \notin I} w_i∑i∈I​wi​=∑i∈/I​wi​ holds (if yes, then accept; otherwise, reject this certificate). If we use w=max⁡iwiw = \max_i w_iw=maxi​wi​, then doing O(n)O(n)O(n) addition operations and checking if the sums are equivalent takes O(nlog⁡w)O(n \log w)O(nlogw) time. This is polynomial in the input size.

We show that Partition is NP-Hard by showing a reduction from Subset Sum.

Let numbers a1,…,ana_1, \dots, a_na1​,…,an​ with target sum AAA be a Subset Sum instance. First, we add up all numbers and let A‾=∑i=1nai−A\overline{A} = \sum_{i = 1}^n a_i - AA=∑i=1n​ai​−A. We assume without loss of generality that A≥A‾A \ge \overline{A}A≥A. We create an input to Partition that uses n+1n + 1n+1 numbers: a1,…,ana_1, \dots, a_na1​,…,an​ from Subset Sum and one additional number an+1=A−A‾a_{n + 1} = A - \overline{A}an+1​=A−A.

Letting a=max⁡iaia = \max_i a_ia=maxi​ai​, this reduction takes O(nlog⁡a)O(n \log a)O(nloga), as we need to do O(n)O(n)O(n) addition/subtraction operations to create our new element an+1a_{n + 1}an+1​ (since these are large numbers, we take O(log⁡a)O(\log a)O(loga) time for each addition operation). Therefore, our reduction runs in polynomial time.

The intuition for this reduction is as follows: if there exists such a subset III such that ∑i∈Iai=A\sum_{i \in I} a_i = A∑i∈I​ai​=A, then the remaining elements sum to A‾=∑i=1nai−A\overline{A} = \sum_{i = 1}^n a_i - AA=∑i=1n​ai​−A. So a yes-instance of Subset Sum splits the numbers into two groups with sums AAA and A‾\overline{A}A. This is almost a partition; both sides aren't always balanced, they differ by A−A‾A - \overline{A}A−A. Adding in an extra number an+1=A−A‾a_{n + 1} = A - \overline{A}an+1​=A−A closes this gap on the A‾\overline{A}A side and makes the two sums equal to AAA. In other words, an+1=A−A‾a_{n + 1} = A - \overline Aan+1​=A−A is a "balancing weight" that turns an uneven Subset Sum split into an even partitioning.

(⇒)(\Rightarrow)(⇒) Suppose there is a subset III of the subset sum problem with total sum AAA. Then this subset satisfies the parition rule for the input we created. Since we have ∑i=1n+1ai=2A\sum_{i = 1}^{n + 1} a_i = 2A∑i=1n+1​ai​=2A, the remaining items not selected in III will sum to AAA. Thus, we have a solution to Partition.

(⇐)(\Leftarrow)(⇐) Suppose our constructed Partition instance has a partition of the n+1n + 1n+1 numbers with equal sums. Note that ∑i=1n+1ai=2A\sum_{i = 1}^{n + 1}a_i = 2A∑i=1n+1​ai​=2A implies that both sides sum to AAA. We simply chose subset III to be the side of the partition not containing the newly created item an+1a_{n + 1}an+1​, so III is a solution to the Subset Sum problem.

Since we have shown Partition to be in NP and NP-Hard, this problem is NP-Complete as required. □\square□
