# Stable Matching

Stable matching is a framework for pairing two groups when each participant has ranked preferences over the other side. Classic examples include matching men to women or hospital to residents. We will use hospital and resident example in our notes.

Given hospitals $h_1, \dots, h_n$ and residents $r_1, \dots, r_n$, each with a ranked preference list over the other side, we want to find a **stable**, **perfect** matching. Calling this matching $M = \{\}$, we want it to have two properties:

- Stable matching: 

When we have a stable is not just whether everyone can be matched, but whether the result is **stable**: there should be no unmatched pair who would both prefer each other over their assigned partners.
